## 1. الشروط والأحكام الفنية والمخفية / Hidden & Technical Terms

| البند / Feature | التفاصيل الفنية / Technical Specification | ملاحظات الاستخدام / Usage Notes |
| :--- | :--- | :--- |
| **وحدة احتساب البيانات (Data Metering Block)** | **100 KB** | يتم تقريب كل جلسة تصفح لأقرب كتلة (كل 100 كيلوبايت) وفق لوائح هيئة الاتصالات CST. |
| **وحدة احتساب المكالمات (Voice Metering)** | **بالثانية (Per second)** | الحساب بالثانية إلزامي لجميع الشبكات المحلية. |
| **مكالمات الواي فاي (WiFi Calling / VoWiFi)** | **مدعومة رسميًا (Supported)** | مدعومة رسميًا على خطوط مسبق الدفع (Mobily VoWiFi) للأجهزة المتوافقة. |
| **الاتصال عبر الجيل الرابع (VoLTE)** | **مدعومة (Supported)** | تتيح نقاء الصوت وإجراء المكالمات دون انقطاع سرعة الإنترنت 4G/5G. |
| **سياسة الاستخدام العادل وخنق السرعة (Throttling / FUP)** | **لا خنق سرعة على حزم البيانات العامة المحددة. باقات السوشيال المفتوح تخضع لسياسة الاستخدام الشخصي المباشر.** | لا يوجد أي خنق سرعة على سعة البيانات العامة المحددة؛ السرعة بأقصى إمكانيات 5G/4G. |
| **بث الإنترنت ونقطة الاتصال (Hotspot / Tethering)** | **الهوتسبوت يُخصم من رصيد البيانات العامة.** | **تنبيه هام:** حزم السوشيال المفتوحة لا تغطي الهوتسبوت؛ أي أجهزة متصلة بالبث تستهلك من رصيد البيانات العامة. |
| **ترحيل البيانات (Data Rollover)** | **غير مدعوم (No)** | البيانات غير المستهلكة تنتهي بانتهاء مدة الباقة. |
