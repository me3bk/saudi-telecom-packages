## 1. الشروط والأحكام الفنية والمخفية / Hidden & Technical Terms

| البند / Feature | التفاصيل الفنية / Technical Specification | ملاحظات الاستخدام / Usage Notes |
| :--- | :--- | :--- |
| **وحدة احتساب البيانات (Data Metering Block)** | **100 KB** | يتم تقريب كل جلسة تصفح لأقرب كتلة (كل 100 كيلوبايت) وفق لوائح هيئة الاتصالات CST. |
| **وحدة احتساب المكالمات (Voice Metering)** | **بالثانية (Per second)** | الحساب بالثانية إلزامي لجميع الشبكات المحلية. |
| **مكالمات الواي فاي (WiFi Calling / VoWiFi)** | **غير معتمدة رسميًا (Not officially supported)** | خدمة VoWiFi غير معتمدة رسمياً كخدمة قياسية لشرائح ريد بُل. |
| **الاتصال عبر الجيل الرابع (VoLTE)** | **مدعومة (Supported)** | تتيح نقاء الصوت وإجراء المكالمات دون انقطاع سرعة الإنترنت 4G/5G. |
| **سياسة الاستخدام العادل وخنق السرعة (Throttling / FUP)** | **لا خنق سرعة على جيجاكوين البيانات العامة.** | لا يوجد أي خنق سرعة على سعة البيانات العامة المحددة؛ السرعة بأقصى إمكانيات 5G/4G. |
| **بث الإنترنت ونقطة الاتصال (Hotspot / Tethering)** | **الهوتسبوت يخصم من رصيد البيانات العامة.** | **تنبيه هام:** حزم السوشيال المفتوحة لا تغطي الهوتسبوت؛ أي أجهزة متصلة بالبث تستهلك من رصيد البيانات العامة. |
| **ترحيل البيانات (Data Rollover)** | **نعم مدعوم (Yes)** | نظام الجيجاكوين (Gigacoins): تتحول جميع البيانات المتبقية غير المستخدمة إلى جيجاكوين لا تنتهي صلاحيتها أبداً طالما شريحتك نشطة! |
