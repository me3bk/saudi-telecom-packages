# مشروع دليل ومقارنة باقات الاتصالات السعودية مسبقة الدفع
# Saudi Telecom Prepaid Packages & Analysis Project

مشروع متكامل ومفصل يجمع كافة باقات مسبق الدفع (شحن) لجميع مشغلي الاتصالات في المملكة العربية السعودية، مستخرجة ومحققة مباشرة من المواقع الرسمية ولوائح هيئة الاتصالات والفضاء والتقنية (CST).

---

## 📁 هيكلية المشروع / Project Structure

```
saudi-telecom-packages/
├── README.md                      # دليل المشروع وخريطة الملفات (عربي / إنجليزي)
├── packages.json                  # قاعدة بيانات JSON الكاملة لجميع الباقات والشروط
├── hidden_terms_guide.md          # الدليل الفني للشروط المخفية (وحدة الحساب، VoWiFi، خنق السرعة)
├── comparison_70_115_sar.md       # جدول تحليلي متخصص لفئة 70 - 115 ريال مع التركيز على البيانات العامة
├── index.html                     # لوحة تحكم وتطبيق تفاعلي للمقارنة والتصفية بدون إنترنت
└── providers/                     # ملفات تفصيلية لكل مشغل على حدة
    ├── stc.md                     # إس تي سي (سوا)
    ├── jawwy.md                   # جوّي من stc
    ├── virgin.md                  # فيرجن موبايل (شبكة stc)
    ├── mobily.md                  # موبايلي
    ├── lebara.md                  # ليبارا (شبكة موبايلي)
    ├── zain.md                    # زين السعودية
    ├── yaqoot.md                  # ياقوت (شبكة زين)
    ├── salam.md                   # سلام موبايل (شبكة زين)
    └── redbull.md                 # ريد بُل موبايل (شبكة زين)
```

## 💡 كيفية استخدام لوحة التحكم التفاعلية
افتح ملف `index.html` في أي متصفح ويب للاستمتاع بالمقارنة التفاعلية، الفلترة بالسعر، نوع الشبكة، وترتيب الباقات حسب البيانات العامة أو السعر أو الدقائق مع دعم اللغتين العربية والإنجليزية.
